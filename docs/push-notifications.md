# 自动推送与多通道通知配置指南

本文档介绍如何在 **A-Share Agent 智能投研平台** 中配置并使用多通道自动推送功能。

平台支持在**每个交易日 15:30 收盘后**，全自动执行 AI 深度大盘复盘与全市场题材挖掘，并将结构化专业研报与潜力个股雷达实时推送到您的**飞书群、钉钉群、企业微信群**或**微信服务号（手机端直达）**。

## 一、支持的推送内容与通道概览

### 1. 推送内容类型

| 通知类型 | 触发时机 | 核心内容 |
| :--- | :--- | :--- |
| **📈 A股每日收盘复盘** | 每个交易日 15:30 收盘后 | 主要指数涨跌幅、全市场成交量与放量情况、多空情绪周期阶段与量化评分、今日领涨主线与热点题材、龙虎榜机构席位动向、次日重点关注自选股推演清单。 |
| **⚡ 题材挖掘与潜力雷达** | 每个交易日 15:30 收盘后 | 基于高流动性池与多量化策略加权打分挖掘的前排潜力个股、最新价、涨跌幅、换手率及触发策略标签（放量突增、均线多头、价值突破等）。 |
| **🚨 系统与行情异动告警** | 盘中触发或定时任务异常 | 大盘快速跳水/暴跌预警、涨跌停异动或系统任务失败预警。 |

### 2. 支持的通知通道对比

| 通道名称 | 呈现格式 | 安全策略 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **🐦 飞书群机器人** | Interactive 富文本卡片 | HMAC-SHA256 签名 | 团队飞书大群、投研协同、卡片排版美观 |
| **🔔 钉钉群机器人** | Markdown 排版 | HMAC-SHA256 加签 | 企业钉钉群、投研交流群 |

## 二、各通道配置步骤详解

### 1. 飞书自定义群机器人 (Interactive Card)

1. 打开飞书客户端，进入您希望接收通知的群聊。
2. 点击群右上角的 **设置（齿轮图标）** -> **「群机器人」** -> **「添加机器人」**。
3. 选择 **「自定义机器人」**，填入机器人名称（如 `A股智能投研助理`）并保存。
4. 在机器人安全设置中：
   - 勾选 **「签名校验」**（系统会自动使用毫秒时间戳与密钥进行 HMAC-SHA256 签名，推荐开启）。
   - 记录下系统生成的 **密钥（Secret）**。
5. 复制系统生成的 **Webhook 地址**（格式为 `https://open.feishu.cn/open-apis/bot/v2/hook/...`）。
6. 将 Webhook 地址与 Secret 填入系统配置面板。

---

### 2. 钉钉自定义群机器人 (Markdown)

1. 打开电脑端钉钉，进入目标群聊。
2. 点击右上角 **群设置** -> **「智能群助手」** -> **「添加机器人」**。
3. 选择 **「自定义 (通过 Webhook 接入)」**，点击「添加」。
4. 填写机器人名称（如 `A股复盘雷达`）。
5. 在 **安全设置** 中：
   - 勾选 **「加签」**（系统支持标准钉钉加签，加签密钥以 `SEC` 开头）。
   - 复制生成的加签密钥 `SEC...`。
   - *提示：请勿勾选“自定义关键词”，以避免因格式变动导致拦截。*
6. 复制生成的 **Webhook 地址**（格式为 `https://oapi.dingtalk.com/robot/send?access_token=...`）。
7. 将 Webhook 地址与加签 Secret 填入系统配置面板。

---

### 3. 企业微信群机器人 (Markdown)

1. 打开企业微信，进入目标群聊。
2. 右键群聊或在群设置中选择 **「添加群机器人」** -> **「新创建一个机器人」**。
3. 填入机器人名称（如 `A股每日复盘`）并点击添加。
4. 复制生成的 **Webhook 地址**（格式为 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...`）。
5. 将 Webhook 地址填入系统配置面板。

---

### 4. 微信服务号直达 (WxPusher)

如果希望在个人手机微信中直接弹出消息，无需下载企业微信、飞书或钉钉客户端，推荐使用 WxPusher：

1. 浏览器访问 [WxPusher 开放平台](https://wxpusher.zjiecode.com/)，微信扫码注册并登录。
2. 进入后台导航栏 **「应用管理」** -> **「创建应用」**：
   - 应用名称：填入 `A股投资助手`。
   - 联系方式与关注提示等按需填写，保存创建。
3. 在应用列表中找到刚创建的应用，复制其 **`appToken`**（以 `AT_` 开头）。
4. 在左侧菜单点击 **「用户管理」** -> **「关注应用」**：
   - 使用您自己的手机微信扫码关注应用二维码并关注 WxPusher 服务号。
   - 关注成功后，页面列表中会显示您的微信昵称以及专属的 **`UID`**（以 `UID_` 开头）。
5. 将 `appToken` 填入系统的 Token 输入框，将 `UID` 填入接收人 UID 输入框（若需要推送给多个人，多个 UID 之间用半角逗号 `,` 分隔）。

## 三、如何在平台中启用与配置

### 方式一：Web 界面可视化配置（推荐）

1. 登录智能投研平台 Web 界面。
2. 点击左侧/顶部导航栏中的 **「设置」**（或头像下拉菜单中的「个人设置」）。
3. 找到 **「自动推送与通知通道」** 配置卡片：
   - 开启 **「启用自动定时推送」** 总开关。
   - 按需勾选 **「自动推送每日收盘复盘」** 与 **「自动推送题材与潜力雷达」**。
   - 在各通道对应区域填入获得的 Webhook 地址与密钥。
   - 各通道均提供独立的 **开启/暂停** 开关，您可以随时临时静音某个通道而无需清除配置密钥。
4. **一键连通性测试**：
   - 点击各个通道卡片右上角的 **「测试连通性」** 按钮。
   - 系统将立即向对应通道发送一条验证消息。若配置无误，群内/微信将立即收到测试卡片，界面弹出成功提示。
5. 点击底部 **「保存通知配置」** 即可持久化生效。

> [!NOTE]
> 交易日收盘后的自动推送由后台任务触发（无用户上下文），因此**管理员保存的通道配置会自动同步为全局基线**；普通用户保存的配置仅在本人发起的请求中生效。单实例部署只需管理员配置一次。

### 方式二：环境变量 / .env 文件配置

适合 Docker 镜像部署或纯无头服务器环境。在项目根目录的 `.env` 中配置对应变量：

```bash
# ==========================================
# 自动推送与通知通道配置
# ==========================================
# 总开关
PUSH_AUTO_ENABLED=true
PUSH_DAILY_REVIEW_AUTO=true
PUSH_POTENTIAL_AUTO=true

# 1. 飞书群自定义机器人
PUSH_FEISHU_ENABLED=true
FEISHU_WEBHOOK_URL="https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx"
FEISHU_WEBHOOK_SECRET="your_feishu_secret_here"

# 2. 钉钉群自定义机器人
PUSH_DINGTALK_ENABLED=true
DINGTALK_WEBHOOK_URL="https://oapi.dingtalk.com/robot/send?access_token=xxxxxxxx"
DINGTALK_WEBHOOK_SECRET="SECxxxxxxxx"

# 3. 企业微信群机器人
PUSH_WECOM_ENABLED=true
WECOM_WEBHOOK_URL="https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx"

# 4. 微信服务号直达 (WxPusher)
PUSH_WXPUSHER_ENABLED=true
WXPUSHER_APP_TOKEN="AT_xxxxxxxx"
WXPUSHER_UIDS="UID_xxxxxxxx,UID_yyyyyyyy"
```

修改后重启容器或后端服务：
```bash
docker compose restart backend
# 或者本地开发环境：
./start.sh
```

## 四、核心架构与保障机制

平台的通知中枢具备高可靠生产级设计：

1. **异步领域事件总线（EventBus 解耦）**：
   - 每日复盘与选股雷达完成计算后，仅对外发布标准领域事件（`daily_review.completed`、`potential_stocks.mined`）。
   - 计算逻辑与外部网络推送彻底解耦，即便外部 Webhook 接口不可用，也绝不会阻塞或影响核心分析流程。
2. **瞬态网络容错与指数退避重试（Resilient Retry）**：
   - 通道客户端内建指数退避重试（Exponential Backoff with Jitter）。
   - 自动识别并容错处理上游平台的网络超时、连接闪断、429（限流）及 502/503/504 服务器故障，最大程度保障消息送达率。
3. **短期幂等防抖机制（Debounce）**：
   - 同一类别、同一日期的通知在 3 分钟内具备自动幂等拦截机制，防止手动重新计算或调度重入造成群内刷屏。
4. **全链路审计日志持久化**：
   - 每次推送执行均会原子持久化审计记录（包含各通道发送状态、耗时毫秒数与错误明细）。
   - 在 Web 设置页面可随时展开 **「查看最近通知投递审计记录」**，并支持一键清空审计历史。

## 五、常见问题排查 (FAQ)

### Q1: 点击「测试连通性」提示“签名校验失败”或“sign match fail”？
- **飞书**：请检查输入的 Secret 是否包含首尾多余空格；确认飞书机器人的“安全设置”中确实勾选了“签名校验”，且输入的密钥与飞书后台一致。
- **钉钉**：请确认 Secret 是以 `SEC` 开头的加签密钥，而非 access_token；在钉钉后台请确保安全设置仅开启了“加签”，没有设置相互冲突的关键词过滤。

### Q2: 为什么测试消息能收到，但收盘后没有自动推送？
1. 检查设置页面中的 **「启用自动定时推送」** 总开关是否开启。
2. 确认当天是否为 **A 股法定交易日**（周末与节假日系统自动休市，不生成每日复盘）。
3. 检查特定业务开关（如「自动推送每日收盘复盘」）是否被单独关闭。
4. 查看设置卡片底部的「最近通知投递审计记录」，排查是否有防抖跳过提示（同一天 3 分钟内防抖拦截）或通道报错信息。

### Q3: WxPusher 提示发送成功，但手机微信没有收到通知？
1. 检查微信中是否已开启关注该 WxPusher 账号的消息提醒，未将其置于免打扰列表。
2. 登录 WxPusher 开放平台后台，在「发送记录」中确认该 UID 的消息投递状态。
3. 确认 UID 填写无误（必须以 `UID_` 开头）。

### Q4: 如何手动触发一次立即推送测试？
- 可以在前端设置卡片中直接点击各个通道对应的 **「测试连通性」** 按钮；
- 或者通过管理端/API 接口手动触发一次复盘计算，系统会自动广播并完成多通道推送。
